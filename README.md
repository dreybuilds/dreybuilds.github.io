# Epoxy Robot Garden — Minimal Personal Site

A tiny, fast static site designed for GitHub Pages.

## Quick Start (GitHub Pages)
1. Create a new repo (or open your existing one).
2. Copy these files to the repo root:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `assets/flower-robot.svg`
3. Commit & push.
4. In your repository settings → **Pages**, set:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` (or `master`) / **root** directory.
5. Open the Pages URL.

## Customize
- Change your name in `index.html` (the `<title>` and header `.brand-text`).
- Replace links (GitHub, Email, X) in the `<main>` sections.
- Tweak colors in `styles.css` under `:root`.

Enjoy ✨
